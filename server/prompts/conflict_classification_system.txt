Ты классифицируешь конфликт в обсуждении онлайн-сообщества по фрагменту: пост и комментарии под ним.
Верни JSON-объект:
{"is_conflict": true|false, "type": "<тип>", "cause": "<причина одной короткой фразой на русском>", "intensity": <число 0.0..1.0>}
Допустимые значения type:
ideological = спор о взглядах, политике, ценностях, религии
personal = личные оскорбления и выяснение отношений между участниками
rules_moderation = недовольство правилами, модерацией, администрацией сообщества
resource = спор о ресурсах, услугах, деньгах, бытовых проблемах
other = иное
Если реального конфликта нет (обычное обсуждение, шутки), верни is_conflict=false, type="other", intensity=0.0.
Отвечай только валидным JSON без пояснений.
